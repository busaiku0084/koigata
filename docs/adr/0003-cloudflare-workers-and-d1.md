# 0003. Cloudflare Workers と D1 で動かす

- ステータス: 採用
- 日付: 2026-10-11
- 関連: [ADR 0005](0005-access-log-in-d1.md)

## 背景

無料か安価に始めたい。SNS からの流入は瞬間的に増えることがある。いずれ広告や課金で収益化する。初回のデプロイからアクセスログを残したい。

## 決定

- Cloudflare Workers で Hono を動かし、HTML はサーバー側で Hono JSX から作る
- 画像・CSS・JS は Workers Assets（`public/`）から配る
- DB は D1。今はアクセスログだけを入れる
- ブラウザ側の処理は `client/app.ts` を esbuild でまとめた 1 ファイルだけ。フロントのフレームワークは使わない

## 理由

- 無料枠が大きく（Workers 10 万リクエスト/日、静的ファイルは無料で無制限）、商用利用もできる
- エッジで動くので、急に流入が増えても落ちにくい
- D1 が同じアカウントで使え、ログの保存に別のサービスを契約しなくてよい
- 画面は 5 種類だけで、状態を持つのは診断の進行だけ。React などを入れるほどではない

## 検討した他の案

- Vercel + Next.js: OGP 画像の生成は楽だが、無料の Hobby プランは商用利用不可。収益化するときに有料プランが必須になる
- GitHub Pages など静的ホスティングだけ: アクセスログをサーバー側で取れず、外部の解析ツールが必要になる
- VPS: 運用の手間と、流入が急に増えたときの心配がある

## 影響

- Node.js の API はそのまま使えない（Workers のランタイム）。依存を足すときは Workers で動くか確かめる
- ローカルは `wrangler dev`（workerd）で本番とほぼ同じ形で動く
