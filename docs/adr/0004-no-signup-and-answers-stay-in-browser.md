# 0004. 会員登録を作らず、回答はブラウザの中だけで計算する

- ステータス: 採用
- 日付: 2026-10-11
- 関連: [ADR 0005](0005-access-log-in-d1.md)

## 背景

登録不要で使えるサービスにする。恋愛の診断の回答は、本人にとって人に見られたくない情報になりうる。

## 決定

- 会員登録・ログインは作らない。氏名・メールアドレスなどの個人情報は受け取らない
- 質問と判定（`src/lib/score.ts`）はブラウザにも配り、回答はブラウザの中だけで計算する。サーバーが受け取るのは結果のタイプだけ
- Cookie は使わない

## 理由

- 登録の手間は離脱の一番の原因になる
- 回答も個人情報も持たなければ、漏れる心配がなく、プライバシーページも短く済む

## 検討した他の案

- 回答をサーバーに送って判定する: 判定を隠せるが、隠す価値がない（結果ページは誰でも見られる）。回答を持つことになる
- 匿名 ID を Cookie で持つ: 再訪の分析はしやすいが、同意の扱いが増える。日ごとのハッシュで足りる（ADR 0005）

## 影響

- 有料レポートを売るときも登録は作らない。購入後のページの URL を「鍵」にする方針（docs/plan.md）
- この方針を変えるときは、新しい ADR を書き、`/privacy` も直す
