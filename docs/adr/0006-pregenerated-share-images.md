# 0006. シェア用の画像は事前に作ってコミットする

- ステータス: 採用
- 日付: 2026-10-11
- 関連: [ADR 0002](0002-love-type-quiz-first.md)

## 背景

X・LINE のリンクカード（OGP、1200x630）と、Instagram のストーリーズ用の縦長画像（1080x1920）が要る。

## 決定

- `scripts/gen-images.ts` で SVG を組み立て、resvg で PNG にして `public/og/`・`public/story/` に書き出し、コミットする
- 書体は Noto Sans JP Bold（SIL OFL）を `assets/fonts/` に置き、システムの書体は読まない
- Instagram へは Web Share API（`navigator.share({ files })`）で画像を渡し、使えない環境では画像を開いて保存してもらう
- CI で画像を作り直し、コミットされたものと差がないことを確かめる

## 理由

- 結果が 8 種類しかないので、実行時に作る必要がない。Workers で日本語の画像を作ると書体の読み込みで重く、遅くなる
- 書体をリポジトリに置けば、どの環境でも同じ画像になる

## 検討した他の案

- 実行時に作る（satori / workers-og）: 名前入りなど結果が無限になったら必要。今は過剰
- Instagram の API で投稿する: ログインと審査が要る。登録不要の方針（ADR 0004）と合わない

## 影響

- タイプの文言・色を変えたら `pnpm gen:images` を実行してコミットする（忘れると CI が落ちる）
- 相性診断などで組み合わせが増えても、64 枚程度までは事前生成で足りる
