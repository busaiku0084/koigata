# 0008. 「伝え方（言葉 / 行動）」の軸を足して 16 タイプにする

- ステータス: 採用
- 日付: 2026-10-11
- 関連: [ADR 0002](0002-love-type-quiz-first.md)（タイプ数の部分を置き換える）

## 背景

最初は 3 軸 8 タイプにしていた。タイプが少ないと「友達と同じタイプだった」が増え、結果を見せ合う楽しさが薄い。16Personalities のように 16 タイプほどほしい。

あわせて、軸が何にもとづくかを残しておきたい。

## 決定

軸を 1 つ足して 4 軸・16 タイプ・12 問（1 軸 3 問）にする。

| 軸 | 文字 | 下敷きにした考え方 |
|---|---|---|
| approach（動き方） | A 自分から動く / P 様子を見る | 恋愛での主導性（誘う・告白する・計画するのは誰か） |
| temperature（恋の温度） | H 燃え上がる / C じっくり温める | リーの恋愛の色彩理論のエロス（情熱的な愛）とストルゲ（友愛的な愛） |
| distance（距離感） | D いつも一緒 / I ひとりの時間も大事 | 愛着理論の、親密さを求めるか自立を保ちたいか |
| expression（伝え方） | V 言葉で伝える / B 行動で示す | チャップマンの「5 つの愛の言語」の、肯定的な言葉とそれ以外（奉仕・贈り物・時間・触れ合い） |

- 8 タイプはそれぞれ「言葉派」と「行動派」に分けた。もとの 8 つの名前と slug はどちらかに残している（まだ公開前なので、slug を付け直してよい最後の機会）
- 相性のいい相手は「動き方と温度が逆、距離感と伝え方が同じ」タイプにする。引っぱる側と待つ側・熱さと落ち着きで補い合い、一緒にいたい度合いと愛情の伝え方はそろっているほうがすれ違いにくい、という考え。規則はテストで守る

## 理由

- 2⁴ = 16 なので、軸の組み合わせだけで全タイプが作れ、どの回答でも必ずどれかに決まる
- 伝え方は結果の説明に具体的なアドバイス（「たまには言葉で」「行動でも示して」）を書きやすく、相性の話にもつながる
- 4 軸とも、よく知られた恋愛心理学の考え方を下敷きにしているので、説明がつく

## 検討した他の案

- 恋の見方（ロマン / 現実）: 結婚観まで話を広げやすいが、温度の軸と意味が近く、回答が偏りやすい
- 感情の出し方（素直 / 秘める）: 共感は集めやすいが、結果の文言が嫉妬や不安などネガティブ寄りになりやすい
- 8 タイプのまま公開してログを見る: 公開後に slug を変えるとシェア済みのリンクが切れるので、増やすなら今がよい

## 影響

- 質問が 9 問から 12 問に増え、診断の時間が少し延びる。完了率をログ（quiz_start → quiz_complete）で見る
- 心理テストとしての妥当性は検証していない。サイトでは引き続き「エンタメとして」と書く
- 軸を増やす・変えるときは、新しい ADR を書く（slug が変わるなら旧 URL からのリダイレクトも用意する）
