# 0007. ローカルのポートは 127.0.0.1 の 47310・47311 に固定する

- ステータス: 採用
- 日付: 2026-10-11
- 関連: zero-second の ADR 0015（47300〜47303 を使用）

## 背景

同じマシンで本職の開発もしており、3000・8080・9229 などが使われている。個人開発が本職の開発環境に影響しないことを最優先にする。

## 決定

- `wrangler dev` は 127.0.0.1 の 47310、デバッガ（inspector）は 47311 にする（`package.json` の `dev`）
- ほかのポートが要るときは 47312〜47319 から選ぶ

## 理由

- 4731x は zero-second（4730x）と重ならず、一般的な開発ツールの既定とも重ならない
- wrangler の既定（8787 と inspector の 9229）は、Node.js のデバッガなど本職の作業とぶつかりうる
- 127.0.0.1 に限れば LAN から見えず、0.0.0.0 で待ち受ける本職のサービスとも衝突しない

## 検討した他の案

- wrangler の既定のまま: 9229 は Node.js のデバッガの既定で、本職とぶつかる

## 影響

Docker は使っていない。使うときは zero-second と同じく、compose のプロジェクト名を `koigata` に固定する。
