# 企画とマネタイズの段取り

## なぜ「恋愛タイプ診断」か

ゲームと恋愛占いの 2 案から、まず恋愛タイプ診断にした。

- **結果が「タイプ」なのでシェアされやすい**。「私は○○型だった」は自己紹介として投稿しやすく、見た人が「自分は？」と診断しに来る。占いの「今日の運勢」より、結果を他人に見せたくなる
- **結果が 8 種類に決まっているので、シェア画像を事前に作っておける**。実行時の画像生成が要らず、無料枠で速く動く
- **回答をサーバーに送らずに済む**。登録不要・個人情報なしで成り立つ
- ゲームは面白さの作り込みに時間がかかり、当たり外れが大きい。診断で集客の仕組み（シェア → 流入 → 診断 → シェア）を先に作り、ゲームは後から同じ仕組みに載せられる

## 成長の仕組み

```
シェア画像を見る → 結果ページ（?s=x など）→ 「あなたも診断」→ 診断 → 結果をシェア
```

アクセスログでこの輪の各段の数（流入・診断開始・完了・シェア）を毎日見る。
まず見る指標は **診断完了あたりのシェア率** と **シェア 1 回あたりの流入数**。

## マネタイズの段取り

| 段階 | やること | 始める目安 |
| --- | --- | --- |
| 0. 今 | 無料の診断だけ。詳細レポートは「準備中」ボタンでクリック数を測る（`teaser_click`） | — |
| 1. 広告 | 結果ページに広告枠（AdSense など）。プライバシーページに外部送信を追記する | 月 1 万 PV 程度 |
| 2. 相性診断 | 「友達にも診断してもらう」リンク → 2 人のタイプの相性ページ。シェアの輪を太くする本命 | 完了 → シェア率が見えてから |
| 3. 有料の詳細レポート | 登録なしの単品購入（Stripe Checkout）。購入後のページの URL をそのまま「鍵」にする | `teaser_click` が完了数の数 % を超えたら |
| 4. 診断の追加 | 別テーマの診断・ゲームを同じ基盤（ログ・シェア画像・結果ページ）に足す | 1 本目が回り始めたら |

有料化や広告を入れるときは、特定商取引法の表記・プライバシーページの更新（外部送信規律）を同じ PR で行う。
